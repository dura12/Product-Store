# Product-Store-

# 🛍️ Full Stack Product Management App

A full-featured product management application built with the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) and styled using **Chakra UI**. This app allows users to create, view, update, and delete products with a responsive and sleek UI.

## ⚙️ Tech Stack

- ⚛️ **Frontend**: React.js + Chakra UI  
- 🖥️ **Backend**: Node.js + Express.js  
- 🗃️ **Database**: MongoDB  
- 📦 **Package Manager**: npm

---

## ✨ Features

- 🔥 Build and consume a full RESTful API
- 🖼️ Create, Read, Update, Delete (CRUD) products
- 📱 Responsive UI with Chakra UI
- 🐞 Robust error handling on both frontend and backend
- 🌐 Easy deployment ready
- 🎯 State management using Zustand
- 💬 Toast notifications for better UX
- 🧹 Clean and reusable component structure
